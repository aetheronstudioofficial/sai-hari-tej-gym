# 🏋️‍♂️ Sai Hari Tej Gym

Welcome to the official repository for the **Sai Hari Tej Gym** website. This is a premium, modern, and highly interactive web application designed to showcase the facilities, trainers, membership options, and transformation stories of the best fitness center in Anekal, Karnataka.

Built with a state-of-the-art tech stack, the web app offers a sleek dark-themed aesthetic, smooth interactive micro-animations, and an intuitive user experience.

---

## ✨ Features

- **🎯 Interactive Goal Selector**: Tailored workout suggestions based on target outcomes.
- **🧮 BMI Calculator**: Real-time BMI calculation to help users understand their health metrics.
- **💪 Dynamic Transformations**: Interactive before/after progress showcase.
- **📋 Premium Memberships**: Clear breakdown of Monthly, Quarterly, Half-Yearly, and Elite Annual plans.
- **🗺️ Interactive Location & Contact**: Integrates maps and contact info for easy navigation.
- **✨ Fluid Animations**: Smooth, premium scroll and transition effects powered by Framer Motion.
- **📱 Fully Responsive**: Seamlessly optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Core**: [React 19](https://react.dev/) & [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [TailwindCSS v4](https://tailwindcss.com/) & [PostCSS](https://postcss.org/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended) along with `npm` or `yarn`.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aetheronstudioofficial/sai-hari-tej-gym.git
   cd sai-hari-tej-gym
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Development

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Build & Lint

To ensure code quality and compile the project for production, run:

```bash
# Run ESLint validation
npm run lint

# Compile and build the production bundle
npm run build
```
